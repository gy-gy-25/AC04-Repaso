# AC04-Repaso

Ejercicio de repaso de Kotlin centrado en el uso de colecciones y funciones de orden superior.

El programa trabaja con una lista de temperaturas en grados Celsius y:

- Filtra las temperaturas superiores a `30 °C`.
- Convierte las temperaturas filtradas a Fahrenheit.
- Muestra las temperaturas convertidas individualmente.
- Calcula la temperatura media.
- Obtiene la temperatura máxima, contemplando el caso de una lista vacía.

## Ejemplo de salida

```text
[31.2, 34.8]
[88.16, 94.64]
88.16
94.64
La media de las temperaturas es: 27.88
La temperatura máxima es: 34.8
```
